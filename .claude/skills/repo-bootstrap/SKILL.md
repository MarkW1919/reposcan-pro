# Repo Bootstrap Skill

## Purpose
Initialize a new project from scratch.

## Tasks
- create folder structure
- define modules
- define service boundaries
- create initial config files

## Required structure
- backend or `apps/api`
- frontend or `apps/ui`
- AI/ML under `ml/`
- `scripts/`
- `docs/`

## Workflow
1. Read `CLAUDE.md` and the canonical docs before changing structure.
2. Establish the repo skeleton before writing implementation code.
3. Add config, scripts, and placeholders that make boundaries explicit.
4. Keep datasets, weights, and generated artifacts out of git.

## Output
- complete repo skeleton
- module descriptions
