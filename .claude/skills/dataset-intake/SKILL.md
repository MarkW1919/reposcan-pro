# Dataset Intake Skill

## Purpose
Assess whether a new dataset is suitable for long-range, low-light RepoScan Pro training and evaluation.

## Inputs
- dataset source and license
- annotation format
- sample imagery

## Workflow
1. Check license, provenance, and region relevance.
2. Review imaging realism: distance, blur, lighting, glare, and plate scale.
3. Confirm annotation completeness and split strategy.
4. Decide whether to accept, reject, or quarantine the dataset pending cleanup.

## Output
- intake decision
- data quality findings
- cleanup or relabeling requirements
